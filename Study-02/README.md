# 할 일 관리

하루 할 일을 업무·개인·공부로 나눠 관리하고 진행률을 한눈에 보는 개인용 웹 앱입니다. HTML·CSS·순수 자바스크립트 3개 파일로 되어 있고, 설치나 서버 없이 브라우저에서 바로 실행됩니다. 요구사항은 [할 일 관리 앱 PRD.md](할%20일%20관리%20앱%20PRD.md)에 있습니다.

## 실행

`index.html`을 더블클릭하면 기본 브라우저에서 열립니다. 터미널에서는 다음과 같이 엽니다.

```bash
open index.html        # macOS
start index.html       # Windows
```

넓은 화면에서 쓸 때는 데스크톱 버전 `web_version/index.html`을 엽니다. 왼쪽 사이드바에 진행률·카테고리 필터·관리 버튼, 오른쪽에 입력창과 목록이 놓이는 2단 화면이고, 기능은 같습니다. 창 폭이 760px보다 좁아지면 모바일 버전과 같은 한 줄 화면으로 바뀝니다. 두 버전은 같은 저장 공간을 쓰므로 데이터도 같이 보입니다.

데스크톱 버전에만 있는 기능:

- **진행 중 / 완료 묶음**: 미완료 항목이 위, 완료 항목이 아래(1600px 이상 화면에서는 두 열로 나란히).
- **순서 바꾸기**: 항목을 드래그하거나 `Alt`+`↑`/`↓`. 바꾼 순서는 저장됩니다.
- **여러 개 선택**: `Ctrl`/`⌘`+클릭, `Shift`+클릭, `X`, `Shift`+`↑`/`↓`, `Ctrl`/`⌘`+`A`. 선택하면 입력창 아래 막대에서 한 번에 완료·카테고리 변경·삭제.
- **우클릭 메뉴**: 수정·완료 전환·카테고리 변경·삭제 (`Shift`+`F10`으로도 열림).
- **단축키**: `/`·`N` 입력창, `1`~`4` 필터, `↑`/`↓` 항목 이동, `F2` 수정, `Delete` 삭제. 전체 목록은 `?` 또는 사이드바의 "단축키 보기".

데이터는 브라우저의 localStorage에 저장되어 새로고침이나 브라우저 재시작 후에도 유지됩니다. 브라우저마다, 시크릿 창마다 저장 공간이 따로이며, 시크릿 창은 닫으면 데이터가 사라집니다.

## 기능

- **추가**: 제목(최대 100자)과 카테고리를 고르고 Enter 또는 추가 버튼. 고른 카테고리는 다음 추가 때도 유지됩니다.
- **자동 분류**: 제목에 "회의", "장보기", "영어" 같은 키워드가 있으면 입력하는 동안 카테고리가 자동으로 바뀝니다. 드롭다운을 직접 고르면 그 선택이 우선합니다. 키워드는 `app.js`의 `CATEGORIES`에서 고칠 수 있습니다.
  - **자동 재분류**: 이미 있는 할 일을 키워드로 다시 분류합니다. 바뀔 항목을 확인 창에서 미리 보여 줍니다.
  - **분류 설정**: 자동 분류 켜기/끄기, 신뢰도 임계값(50~100%), 재분류 때 완료 항목 포함 여부. 신뢰도는 "가장 많이 맞은 카테고리의 키워드 점수 ÷ 전체 점수"로, 여러 카테고리 키워드가 섞이면 낮아집니다.
- **완료 체크**: 체크박스(Space)로 완료/미완료 전환. 완료 항목은 취소선과 흐린 색으로 표시됩니다.
- **수정**: 제목 더블클릭 또는 ✎ 버튼 → 제목과 카테고리를 그 자리에서 수정. Enter·다른 곳 클릭은 저장, Esc는 취소, 빈 제목은 원래 값 유지.
- **삭제**: ✕ 버튼으로 바로 삭제. 마우스 환경에서는 항목에 마우스를 올리거나 포커스했을 때 버튼이 보입니다. 하단 "완료 항목 삭제"는 확인 창을 거쳐 완료한 항목을 한 번에 지웁니다.
- **카테고리 필터**: 전체·업무·개인·공부 탭(항목 수 표시). 고른 탭은 새로고침 후에도 유지됩니다.
- **진행률**: 전체 "완료 / 전체 (퍼센트)"와 바, 카테고리별 작은 바, 남은 할 일 수. 전체 진행률은 필터와 상관없이 모든 할 일 기준입니다.
- **다크 모드**: 처음에는 운영체제 설정을 따르고, 헤더의 버튼으로 직접 바꾸면 그 선택이 유지됩니다.
- **백업**: 하단 "내보내기"로 `todo-backup-YYYY-MM-DD.json` 다운로드, "가져오기"로 백업 파일을 골라 현재 목록을 대체(확인 창 표시). 형식이 맞지 않는 파일은 안내만 하고 기존 데이터는 그대로 둡니다.

마우스 없이 Tab·Space·Enter·Esc만으로 모든 기능을 쓸 수 있습니다.

## 파일 구성

```
├── index.html   화면 구조, 테마 깜빡임 방지 스크립트
├── style.css    스타일, 라이트/다크 색상 변수
├── app.js       상태 관리, 렌더링, 저장, 백업
└── web_version/ 데스크톱 전체 화면 버전 (app.js는 같고, index.html·style.css는 레이아웃이 다르며 desktop.js가 데스크톱 기능을 더함)
```
