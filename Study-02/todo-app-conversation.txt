⏺ app.js에서 다크 모드를 담당하는 함수는 applyTheme과 toggleTheme 두
  개입니다(app.js:359-373). 함수는 짧은데, 실제로 색을 바꾸는 일은 CSS가 하고 첫
  테마는 index.html이 정하기 때문입니다.

  1. applyTheme(theme) — 테마를 화면에 반영 (app.js:361)

  function applyTheme(theme) {
    const dark = theme === 'dark';
    document.documentElement.dataset.theme = theme;
    themeToggle.setAttribute('aria-pressed', String(dark));
    themeToggle.title = dark ? '라이트 모드로 전환' : '다크 모드로 전환';
    themeToggle.textContent = dark ? '☀︎' : '☾';
  }

  - <html data-theme="..."> 설정:
    - 색을 실제로 바꾸는 것은 이 한 줄입니다.
    - style.css의 :root[data-theme="dark"] 규칙이 이 속성을 보고 --bg, --text,
      --cat-work 같은 색 변수를 덮어씁니다.
    - JS가 색 값을 직접 다루지 않으므로, 배지와 진행률 바처럼 var(--cat-*)를
      쓰는 요소도 자동으로 색이 바뀝니다.
  - aria-pressed:
    - 토글 버튼이 눌린 상태인지 알려 줍니다.
    - 버튼의 aria-label은 "다크 모드"로 고정이어서, 스크린 리더는 "다크 모드,
      토글 버튼, 눌림"처럼 읽습니다.
  - title: 마우스를 올렸을 때 나오는 툴팁으로, 누르면 어떻게 되는지 알려 줍니다.
  - 아이콘: 다크 모드일 때는 ☀︎, 라이트 모드일 때는 ☾로, 바뀔 모드를 보여 줍니다.

  이 함수는 저장소에 아무것도 쓰지 않습니다. 그래서 시작할 때 화면만 맞추는
  용도로도 쓸 수 있습니다.

  2. toggleTheme() — 버튼을 누를 때 전환 (app.js:369)

  function toggleTheme() {
    const next = document.documentElement.dataset.theme === 'dark' ? 'light' :
  'dark';
    writeStorage(STORAGE_KEYS.theme, next);
    applyTheme(next);
  }

  - 현재 테마를 <html>의 data-theme에서 읽습니다. 별도 상태 변수 없이 DOM을
    그대로 기준으로 씁니다.
  - 반대 테마를 localStorage todo-app:theme에 저장한 뒤 applyTheme으로 화면에
    반영합니다.
  - 저장에는 writeStorage를 씁니다. 그래서 저장이 막힌 환경에서도 오류 없이
    전환되고, "저장할 수 없습니다" 안내만 표시됩니다. 이 경우 새로고침하면
    선택이 사라집니다.

  3. 연결 부분

  - 이벤트 (app.js:614): themeToggle.addEventListener('click', toggleTheme);
  - 시작 시 (app.js:642): applyTheme(document.documentElement.dataset.theme === 
    'dark' ? 'dark' : 'light');
    - 첫 테마를 여기서 정하지 않습니다. index.html <head>의 인라인 스크립트가
      이미 정해 둔 값을 읽어, 버튼 아이콘과 aria-pressed만 맞춥니다.

  전체 흐름

  1. 페이지 로드 (index.html <head> 인라인 스크립트, CSS보다 먼저 실행): 저장된
     todo-app:theme을 읽고, 없으면 운영체제 설정(prefers-color-scheme)을 씁니다.
     그 값을 <html data-theme>에 넣습니다. 그래서 흰 화면이 잠깐 보였다가
     어두워지는 깜빡임이 없습니다.
  2. app.js 시작: applyTheme(현재 값)이 버튼 표시만 맞춥니다.
  3. 버튼 클릭: toggleTheme()이 저장한 뒤 applyTheme(반대 값)을 부릅니다.
  4. CSS: :root[data-theme="dark"] 변수가 적용되어 전체 색이 바뀝니다.

  참고: 테마를 저장하지 않았더라도, 페이지가 열린 뒤에 운영체제를 다크 모드로
  바꾸면 화면은 바로 따라가지 않습니다. matchMedia 변경 이벤트를 듣지 않기
  때문이고, 새로고침하면 반영됩니다. 이 동작을 원하시면 추가할 수 있습니다.
