    단축키

    / 또는 N
    할 일 입력창으로 이동
    Esc (입력창에서)
    목록으로 이동
    1~4
    전체·업무·개인·공부 필터
    ↑ ↓ Home End
    목록·필터에서 항목 이동
    Space
    완료 체크
    F2 (또는 더블클릭)
    수정
    Delete / ⌫
    삭제 (여러 개 선택 시 확인 후 삭제)
    Alt+↑ ↓ (또는 드래그)
    순서 바꾸기
    X, Ctrl/⌘+클릭
    선택 추가·해제
    Shift+↑ ↓, Shift+클릭
    범위 선택
    Ctrl/⌘+A (목록에서)
    보이는 항목 모두 선택
    Shift+F10, 우클릭
    항목 메뉴
    Esc
    선택 해제·메뉴 닫기
    ?

    분류 설정

    끄면 입력할 때 자동 분류와 자동 재분류를 모두 쓰지 않습니다.

    신뢰도는 가장 많이 맞은 카테고리의 키워드 점수 ÷ 전체 점수입니다. 여러 카테고리 키워드가 섞이면 낮아지고, 이 값보다 낮으면 분류하지 않습니다. 100%는 한 카테고리 키워드만 있을 때만 분류합니다.
